# Profile · вариант A

Аватар, статистика, две кнопки и текст About размещены ограничениями в `Main.storyboard`. Имя Maximilian Alexander von Habsburg используется для проверки переноса на две строки. Размер аватара 96 × 96, высота кнопок 48 pt и расстояние между ними 12 pt.

Проверить внешний вид в портретной ориентации на iPhone SE (3-го поколения) и iPhone 16 Pro Max.
