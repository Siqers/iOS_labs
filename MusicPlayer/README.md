# Quiet Frequencies

Плеер с десятью синтезированными для проекта инструментальными миниатюрами и собственными иллюстрациями. Все файлы MPEG-4 Audio лежат в проекте и добавлены в ресурсы приложения. После окончания трека плеер автоматически переходит к следующему.

Для сдачи нужны скриншоты на iPhone SE (3-го поколения) и iPhone 16 Pro Max, а также запись на 20–30 секунд. Нажмите Previous на первом треке, чтобы показать переход к последнему, затем Play, Next, Pause.
