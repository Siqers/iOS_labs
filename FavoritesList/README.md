# Trail Atlas

Таблица из двадцати природных маршрутов Центральной Азии. В строке показаны иллюстрация, название, страна и рейтинг. Строки переиспользуются и подстраиваются под длину названия.

Для сдачи нужны скриншоты на iPhone SE (3-го поколения) и iPhone 16 Pro Max и короткая запись прокрутки до конца списка.
