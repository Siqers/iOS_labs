# Peak Roulette

Подборка из десяти природных маршрутов Центральной Азии. На старте отображается одна случайная карточка. При нажатии Show another trail текущая карточка исключается из выбора.

Для сдачи нужны три скриншота из симулятора: экран запуска, карточка в приложении и иконка на домашнем экране.
